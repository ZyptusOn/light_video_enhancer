# Light Video Enhancer v0.5.2

这是面向 Windows 10/11 WinUI 3 前端的一次小型稳定性与体积修复。Windows 7 LTS 可执行文件没有重建，继续使用 v0.5.0 版本。

## 修复

- 主窗口以 1280×900 普通窗口启动，不再强制最大化。
- 修复主页内容偏右、顶部空白通知条和编码区域多余折叠层级。
- 修复模型下载页中文乱码，以及环境扫描后能力信息不刷新的问题。
- 未手动扫描环境或未找到对应能力时，禁用 NV-VFX、RIFE PyTorch 与 CUDA 光流选项。
- 选择失效的外部算法时回退到自动模式，并在启动任务前进行二次校验。

## 体积优化

- WinUI 前端继续使用中英文、自包含单文件发布。
- 后端不再包含 Tk/Tcl GUI 运行库。
- 去除 PyInstaller 包中重复的 FFmpeg DLL，同时保留运行时需要的动态依赖。
- Full 与 Lite 仍使用完全相同的 WinUI 前端。

## 验证

- Python 单元及集成测试：28/28 通过。
- WinUI Release x64：构建通过，0 个错误。
- Lite 冻结后端能力检查通过，H.264、HEVC、AV1 编码器均可识别。
- 实机验证扫描前禁用、扫描后按能力解锁，以及普通窗口启动。
